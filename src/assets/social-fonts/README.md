# Social card fonts

These unmodified static TrueType fonts are bundled for offline, repeatable social card generation. Both use the SIL Open Font License 1.1. The corresponding copyright and license files are included here.

Downloaded from Google Fonts on 2026-09-10 using [the CSS API for Inter 400 and Playfair Display 600](https://fonts.googleapis.com/css2?family=Inter:wght@400&family=Playfair+Display:wght@600). These files have no variable-font `fvar` table.

- [Inter Regular, version 20](https://fonts.gstatic.com/s/inter/v20/UcCO3FwrK3iLTeHuS_nVMrMxCp50SjIw2boKoduKmMEVuLyfMZg.ttf). [Upstream license](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt). SHA-256 `1b08e7fc267a5c7e1d614100f604b83e7e8a0be241f0f288faa2b3ac93a683ba`.
- [Playfair Display SemiBold, version 40](https://fonts.gstatic.com/s/playfairdisplay/v40/nuFvD-vYSZviVYUb_rj3ij__anPXJzDwcbmjWBN2PKebukDQ.ttf). [Upstream license](https://github.com/google/fonts/blob/main/ofl/playfairdisplay/OFL.txt). SHA-256 `8ab6a1db2d7caeb46c742371da500d0f3de1dc6ec6bea2aef0106f678d7a1f8d`.

The version numbers above identify the Google Fonts asset URLs. Update the fonts, license files, provenance, and card cache version together when changing typography.
